Kebijakan privasi

Halaman ini menjelaskan pemrosesan data pada aplikasi Android WasteNot, API di waste-not-api.bccdev.id, dan halaman publik WasteNot. Pengelolanya adalah Oktavianus Samuel Minarto. Pertanyaan dan permintaan data dapat dikirim ke oktaavsm@student.ub.ac.id.

Catatan dan lampiran yang kamu simpan terhubung ke akunmu. Foto scan dikirim saat kamu menjalankan scan, bukan saat sekadar membuka kamera. Foto scan dan foto lampiran catatan memakai alur penyimpanan yang berbeda.

Jangan sertakan wajah, dokumen identitas, alamat, atau informasi sensitif dalam foto dan catatan jika tidak diperlukan.

Data yang diproses dan tujuannya

  • Nama, alamat email, zona waktu, dan pengenal akun digunakan untuk pendaftaran, akses akun, dan penanggalan aktivitas. Server menyimpan hash kata sandi, bukan kata sandi yang dapat dibaca kembali.
  • Token sesi dan masa berlakunya digunakan untuk autentikasi dan pencabutan akses. Token akses dan token penyegaran bukan data yang perlu kamu kirim kepada pengelola.
  • Catatan aktivitas berisi kategori sampah, metode penanganan, berat atau jumlah, tanggal, catatan teks, serta lampiran opsional. Server menggunakannya untuk riwayat, statistik, XP, dan pencapaian akun.
  • Pengenal permintaan dan versi catatan digunakan untuk sinkronisasi, pencegahan pencatatan ganda, dan penanganan konflik perubahan.
  • Permintaan jaringan membawa alamat IP dan metadata teknis ke server atau penyedia layanan yang dituju. Layanan menggunakan informasi permintaan untuk operasional, pembatasan akses, dan penelusuran gangguan. Log operasional dapat tetap tersedia terpisah dari data akun.

Data akun disimpan pada database PostgreSQL backend WasteNot. Berkas foto lampiran disimpan terpisah di penyimpanan privat server dan diakses melalui API yang memeriksa pemilik akun. Ini bukan enkripsi ujung-ke-ujung: sistem server dan pengelola infrastruktur dapat memproses data untuk menjalankan layanan.

Foto dan layanan AI

Setelah kamu memilih untuk melakukan scan, aplikasi mengirim foto ke backend WasteNot. Backend menormalisasi gambar dan mengirimkannya ke layanan deteksi WasteNot yang menjalankan model deteksi objek. Alur ini tidak otomatis menjadikan foto scan sebagai lampiran catatan.

Alur deteksi tidak menyimpan foto scan mentah sebagai lampiran permanen di database. Server menyimpan hasil dan metadata operasi AI, termasuk objek, kondisi yang kamu konfirmasikan, dan rekomendasi, untuk melanjutkan sesi dan menangani permintaan ulang. Operasi AI memiliki masa berlaku sekitar 24 jam dan dibersihkan oleh pekerjaan pemeliharaan; ini bukan jaminan bahwa semua salinan di memori, log infrastruktur, atau cadangan hilang tepat saat masa berlaku berakhir.

Rekomendasi dapat memakai Google Gemini API. Payload rekomendasi berisi jenis objek, kategori, kondisi, pilihan penanganan, indikator risiko, dan bukti panduan yang relevan. Implementasi ini tidak memasukkan foto, nama, email, atau seluruh riwayat akun ke payload Gemini. Jika provider tidak tersedia, layanan dapat memilih metode melalui aturan bukti yang sudah tersedia.

Pemrosesan Google mengikuti ketentuan Gemini API dan kebijakan privasi Google, termasuk perbedaan ketentuan penggunaan data menurut jenis layanan. Kami tidak menjanjikan retensi nol, tidak digunakan untuk pelatihan, atau pemeriksaan manusia oleh provider tanpa bukti konfigurasi layanan yang berlaku. Jangan memasukkan informasi pribadi ke konteks yang tidak diperlukan.

Jika kamu menambahkan foto lampiran ke catatan, berkas diunggah dan disimpan secara terpisah agar dapat dilihat kembali dari akunmu. Backend menormalisasi gambar dan membuang metadata gambar pada proses unggah. Jangan mengandalkan penghapusan metadata untuk menyamarkan informasi yang terlihat di dalam gambar.

Hasil AI bukan pemeriksaan keselamatan atau peninjauan manusia. Kamu tetap perlu memeriksa kondisi barang dan syarat fasilitas penerima.

Penyimpanan Android dan izin

Aplikasi menyimpan salinan catatan, ringkasan server, identitas akun, draf editor, dan antrean perubahan di penyimpanan privat aplikasi. Antrean lokal memungkinkan perubahan menunggu koneksi; status menunggu sinkronisasi berarti server belum tentu menerimanya. Data lokal ini bukan seluruhnya terenkripsi oleh aplikasi.

Token penyegaran disimpan dalam berkas terenkripsi dengan kunci Android Keystore. Preferensi tema dan pengingat juga disimpan di perangkat. Aplikasi menonaktifkan pencadangan Android untuk data aplikasinya, tetapi kebijakan perangkat dan salinan yang dibuat sendiri berada di luar kendali WasteNot.

Foto kamera untuk scan disimpan sementara di cache privat akun. Aplikasi menjadwalkan pembersihan foto scan setelah sekitar satu jam dan dapat menghapusnya lebih awal saat alur ditutup. Penjadwalan Android, kegagalan berkas, atau proses yang dihentikan dapat menunda pembersihan. Foto asli yang kamu pilih dari galeri tetap berada di galeri sampai kamu menghapusnya sendiri.

  • Izin kamera digunakan untuk memotret saat kamu membuka fitur kamera. Menolak izin tidak menghalangi pencatatan manual.
  • Pemilih foto Android memberikan akses ke foto yang kamu pilih. WasteNot tidak meminta izin untuk membaca seluruh galeri.
  • Izin notifikasi bersifat opsional untuk pengingat lokal. Kamu dapat mematikannya lewat aplikasi atau pengaturan Android.
  • Daftar titik pengumpulan tidak memerlukan izin lokasi. Tombol Maps membuka pencarian alamat di aplikasi peta atau browser; penyedia tujuan memproses permintaan menurut kebijakannya sendiri.

Halaman privasi ini tidak memakai formulir, pelacak analitik, cookie, atau penyimpanan browser melalui skrip. Font dan ikon dimuat dari domain WasteNot. Kunjungan tetap menghasilkan permintaan jaringan ke server situs. Tautan eksternal dan email hanya dibuka saat kamu memilihnya.

Penghapusan dan masa penyimpanan

Data akun dan catatan dipertahankan selama diperlukan untuk layanan akun, sampai dihapus melalui fitur yang tersedia. Menghapus aplikasi atau keluar dari akun bukan permintaan penghapusan akun server.

  • Menghapus satu catatan mengeluarkannya dari riwayat aktif dan perhitungan. Backend memakai penandaan hapus untuk catatan, sehingga penghapusan satu catatan bukan janji pemusnahan langsung seluruh baris database.
  • Lampiran yang dilepas, dihapus, atau tidak jadi digunakan dapat dinonaktifkan lebih dahulu. Pembersihan berkas fisik terpisah dari perubahan status database dan dapat tertunda atau gagal. Batas kedaluwarsa lampiran sementara bukan janji pemusnahan berkas tepat waktu.
  • Untuk menghapus akun, buka Profil, lalu Pengaturan dan Hapus akun. Baca konfirmasi dan masukkan kata sandi saat ini. Setelah server menyetujui penghapusan, data milik akun di database aktif dihapus dan sesi dicabut. Pembersihan foto privat dijalankan terpisah dengan percobaan ulang; berkas dapat bertahan sampai proses itu berhasil.
  • Aplikasi membersihkan data lokal akun pada alur penghapusan yang berhasil. Jika permintaan gagal atau perangkat offline, jangan menganggap akun server telah terhapus. Ikuti pesan aplikasi atau hubungi pengelola.

Cadangan database, arsip operasional, log infrastruktur, data pada perangkat lain, dan data yang telah diproses provider dapat memiliki masa simpan terpisah. Penghapusan dari sistem aktif tidak otomatis memusnahkan cadangan atau arsip lama. Kami belum menetapkan jaminan publik tentang batas hari penghapusan semua cadangan; hubungi pengelola untuk meminta rincian yang berlaku.

Jika tidak dapat masuk, kirim permintaan penghapusan ke email pengelola menggunakan alamat akun bila memungkinkan. Pengelola perlu memverifikasi kepemilikan sebelum bertindak. Jangan kirim kata sandi, token sesi, kode pemulihan, atau dokumen identitas tanpa diminta melalui proses yang dijelaskan pengelola.

Pemulihan kata sandi melalui email hanya dapat bekerja bila layanan pengiriman email server telah dikonfigurasi dan tersedia. Pesan kegagalan layanan bukan bukti email telah dikirim.
